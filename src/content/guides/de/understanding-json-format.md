## Was ist JSON?

JSON (JavaScript Object Notation) ist ein leichtgewichtiges Datenaustauschformat. Es ist einfach zu lesen und zu schreiben und sprachunabhängig.

## JSON-Syntaxregeln

Die Syntax von JSON ist streng. Daten müssen in Name/Wert-Paaren vorliegen und durch Kommas getrennt sein. Schlüssel müssen immer in doppelte Anführungszeichen gesetzt werden.

## JSON vs. XML

Vor JSON war XML der Standard. XML ist jedoch ausführlich. JSON ist präziser, ordnet sich direkt Datenstrukturen in modernen Programmiersprachen zu und erfordert weniger Bandbreite.

## Die Herausforderung beim Lesen von JSON

Wenn ein Server mit JSON-Daten antwortet, ist dies normalerweise minimiert, was es für einen Menschen fast unmöglich macht, es zu lesen.
